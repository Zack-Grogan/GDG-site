# Grogan Development Group

A four-page site for Grogan Development Group LLC, Zackariah Grogan’s company in the Tri-Cities. The work on offer is a website fix, forms and appointments, and estimates and invoices. The address is grogan.dev.

## Run locally

```bash
npm install
npm run dev
```

The dev server listens on [http://127.0.0.1:4317](http://127.0.0.1:4317).

An inquiry opens a mail message to info@grogan.dev. If the browser blocks that window, the page shows the message so it can be copied.
